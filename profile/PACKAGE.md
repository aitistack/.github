# AitiStack GitHub Profile

Complete organization profile package.

## Files

- `README.md` - GitHub organization profile README.
- `assets/01-hero.svg` - Building Digital Experiences section.
- `assets/02-profile-capabilities.svg` - Profile, capabilities, status and metrics section.
- `assets/03-technical-arsenal.svg` - Technical Arsenal section.
- `assets/profile.png` - Profile picture used by the profile section.

## Install

Copy the contents of this folder into:

`.github/profile/`

The resulting structure should be:

`.github/profile/README.md`
`.github/profile/assets/01-hero.svg`
`.github/profile/assets/02-profile-capabilities.svg`
`.github/profile/assets/03-technical-arsenal.svg`
`.github/profile/assets/profile.png`

Update the Resume link in the README comment if you later add a resume URL/file.
